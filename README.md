# GodForge Tooltip Helper

Adds a feature to [godforge.gg](https://godforge.gg/) website that allows you to hover over a buff, debuff, or disable to see what they do.

## Install in Chrome

1. On the [project's GitHub page](https://github.com/HennaKristal/GodForgeTooltipHelper), click **Code** > **Download ZIP**. Extract the ZIP to a folder you can keep.
2. Open `chrome://extensions` in Chrome and turn on **Developer mode**.
3. Click **Load unpacked** and select the extracted folder
