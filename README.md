# GodForge Tooltip Helper

Adds a feature to [godforge.gg](https://godforge.gg/) website that allows you to hover over a buff, debuff or disable to see what they do.

## Install in Chrome

1. Open the [latest GitHub release](https://github.com/HennaKristal/GodForgeTooltipHelper/releases/latest). Under **Assets**, download the extension ZIP [GodForgeTooltipHelper-v1.1.0.zip](https://github.com/HennaKristal/GodForgeTooltipHelper/releases/download/v.1.1.0/GodForgeTooltipHelper-v.1.1.0.zip).
2. Extract the ZIP to a folder you intend to keep safe.
3. Open `chrome://extensions` in Chrome and turn on **Developer mode**.
4. Click **Load unpacked** and select the extracted folder

**Note:** Keep the extracted folder in the same location after installation. If you move or delete it, the extension will stop working because Chrome loads its files from that folder.
